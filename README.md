# 延河课堂重要事项雷达

[English](README.en.md) | 简体中文

从自己有权访问的课堂录播或本地媒体中查找点名、作业、考试、成绩规则、调课等通知，并保留原文和可回听的时间位置。

这是一款本机 Web 工作台，不是学校官方产品。模型输出是待核验的候选事项；处理完成或未检出均不保证没有漏句、漏报。

## 功能

- **课程库**：自动留存浏览过的课程和已处理课次；离线查看历史报告，支持搜索、备注、置顶和归档恢复。
- **跨课程一键执行**：勾选多门课程，刷新录播并排队处理；默认跳过已完成或已在队列中的课次，逐门显示读取失败。
- **任务队列**：查看阶段与进度，停止任务、继续中断任务，保留已成功的转写缓存。
- **听课与讲义**：直接搜索已有文字稿、点击时间回放、倍速播放；使用当前分析模型按主题生成章节、摘要与知识点，每个知识点附原文依据。支持中英文讲义、停止续接缓存及 Markdown 导出。
- **报告记录**：按课程、状态和关键词筛选；回看原视频、回听片段，标记人工复核并导出 ZIP。
- **自选模型服务**：音频转写和事项分析可分别选择“自建开源模型”或“线上 API”，支持混合使用；兼容转写/文字/视觉接口，以及 Gemini、Groq、DeepSeek 预设。自建兼容服务可不填密钥，线上服务必须填写。
- **中英文界面**：右上角随时切换，课程名称、备注、字幕和证据保持原语言；提供中英文项目说明。
- **亮暗主题**：亮色、暗色或跟随系统；语言与主题偏好在浏览器保存，禁用存储时也可在当前页面使用。
- **可追溯覆盖范围**：区分音频处理进度和字幕分析进度；保留失败块、音源偏移、时间戳来源与质量提示。

课次总数以本机保存或最近同步的列表为准。不同录像信号、独立话筒和画面辅助可在单门课程中选择。跨课程批量执行默认优先屏幕信号、使用视频原音轨；一次最多 100 个课次。

## 本机启动

需要 Python 3.11+。Windows 可双击 `start_webui.cmd`。其他系统：

```bash
python -m venv .venv
# Linux / macOS
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -e ".[web,media,dev]"
python -m yanhe_sentinel webui
```

打开 <http://127.0.0.1:8765>。在官方登录窗口完成学校认证，再在“模型设置”配置转写和事项服务。不登录也能上传自己的媒体、字幕，或查看已经保存的报告。

Web 工作台只监听本机回环地址。不要直接转发公网端口，它按单用户本机工具设计。

## 配置自建模型与线上 API

打开“模型设置”，分别为音频转写和事项分析选择服务类型。两者互相独立，可用自建转写搭配线上分析，或反过来。自建服务使用兼容接口；音频端点需支持 `/audio/transcriptions` 并返回带时间戳的 `segments`，文字端点需支持 `/chat/completions` 和结构化 JSON 输出。视觉模型必须支持图片输入。

密钥只在当前服务端会话保存，不写入浏览器偏好。留空仅保留**同一服务**已配置的密钥；更换地址、提供商或服务类型时会清除对应旧密钥，避免发给新服务。自建服务若开启鉴权，仍需填写其密钥。远程服务要求 HTTPS；无 HTTPS 的服务器通过 SSH 转发到本机回环地址。

切换模型不会自动重跑已完成任务；在报告中点击重新分析才会再次调用。语言切换仅更改界面，不会调用模型翻译课堂内容。

## 使用自己的开源模型服务器

可选组合为 Qwen3-ASR-1.7B + Qwen3-ForcedAligner-0.6B（权重约 6.54GB），以及 Qwen3-4B（约 8.06GB）。已有兼容文字模型时可复用，无需重复部署。运行依赖、缓存和显存需要额外空间。

详见 [远程模型部署](docs/REMOTE_MODELS.md)。模型在服务器推理，本机只处理媒体分块和界面；自建推理不产生第三方按次 API 费用，但仍占用自己的服务器资源。

云服务的免费额度和可用型号随账户、地区、服务商政策变化，请在自己的控制台核对。项目不会替你开通付费服务，也不会在接口失败时自动切换到其他供应商。

## 使用顺序

1. 在“添加课程”连接官方平台，浏览课程和课次，课程信息会保存到本机课程库。
2. 单门课程可多选课次；跨课程则在“课程库”勾选课程，点击“一键分析所选课程”。
3. 在“任务队列”查看处理进度。课程无法读取时会单独提示；模型设置不完整时不会开始批量排队。
4. 在“报告记录”筛选结果，逐项回听原文；复核勾选不会自动代填。

归档只改变课程列表，不删除录播、字幕或报告。校园会话到期后需要重新登录才能获取新录像，但本机旧报告仍可查看。

## 听课与讲义

在左侧“听课”选择课次，也可从通知报告或课程库中的已处理课次进入。文字稿搜索和时间跳转无需调用模型。点击“生成章节与讲义”后才会使用当前事项分析模型；自建与线上服务均可，线上调用按服务商计费。

长课按最多 160 段字幕、约 15 分钟或约 1 万字的窗口处理，每个窗口再由模型划分主题章节。结构化整理采用标准模式；校验失败时会要求模型用单章重新整理当前窗口，仍不合格则停止并保留缓存。目录可能在窗口边界出现相邻的同主题章节。系统校验章节连续覆盖窗口、引用存在且属于该章，并从原始字幕计算时间、复制证据原文；这不等于自动验证模型概括的语义正确性。字幕缺失、公式或识别错误仍需回看核对。讲义是对已有文字稿的 AI 整理，原始课件文件需另行获取。

成功窗口会缓存到当前任务的私有目录。停止在正在进行的模型请求结束后生效，继续时复用成功窗口；重新生成会再次调用模型。文字稿改变时旧讲义标为过期，重新整理后才可按章节导航。TXT 可整理章节，但没有时间戳时只按字幕编号定位。讲义和原文保存在本机，可离线阅读与导出 Markdown。

升级前若有活动任务，请先停止并保留缓存；重启后重新登录，再在任务队列继续。

## 命令行与测试

```bash
python -m yanhe_sentinel demo --output runs/demo
python -m yanhe_sentinel analyze --subtitle examples/demo.srt --provider openai-compatible --output runs/report
pytest -q
```

模型地址、名称与密钥可通过环境变量配置；字段见 [.env.example](.env.example)。项目不自动加载 `.env` 文件。

测试覆盖真实媒体解码、平台权限保护、缓存恢复、严格证据校验、课程持久化与跨课程批处理。涉及云端和 GPU 的自动测试使用受控响应；测试通过率不是课堂检测准确率。仓库示例及截图只使用合成数据。

## 隐私和发布

录播、字幕、学生姓名、课程备注、导出报告、登录状态与密钥均不属于开源内容。默认忽略 `runs/`、输入媒体、模型权重和凭据文件。发布前运行：

```bash
python scripts/check_publication.py
```

详细边界见 [隐私说明](docs/PRIVACY.md)。请只处理有权访问的课程，尊重学校规则、授课者和同学的隐私。
