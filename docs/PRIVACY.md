# 隐私边界与开源范围

## 本机保存什么

`runs/` 保存已下载媒体、转写缓存、字幕、报告、复核标记和课程库。课程库只保存课程名称、教师、课次信息、备注与本机处理状态，不存学校密码、登录令牌或录播地址。

校园登录令牌和在网页输入的云模型密钥只保存在服务进程的会话内存中。校园密码仅在官方认证窗口输入；重启工作台后需要重新登录。应用提供的高级登录状态导入会向官方接口验证，不能绕过课程权限。

远程 ASR 部署脚本生成自己的服务令牌，它会保存在服务器的 `service.key` 及本机忽略目录中的副本。这个令牌不是校园密码或供应商 API Key，仍应作为凭据妥善保管，不加入 Git。

## 数据发到哪里

音轨分块发送到你明确配置的转写接口。字幕发送到事项模型；只有开启画面辅助才发送抽样截图。远程模型同样会接收这些输入，请使用你信任的服务器，并了解服务端日志策略。

API 地址不能包含用户名、密码或查询参数；远程服务必须 HTTPS。HTTP 仅允许本机回环地址，远程服务器可通过 SSH 隧道接入。服务失败会保留部分状态，不自动切换供应商。

## 本机工作台边界

网页接口检查 Host、Origin 和 CSRF，工作台只绑定回环地址。它是单用户本机工具，不是多人隔离的公网服务；不要通过公开隧道或反向代理向外开放。

官方课次权限会在下载前再次检查。退出登录不会删除已下载的课程或报告，且批量分析仍需要有效登录。

## 哪些内容不应发布

- 真实课程录像、音频、字幕、学生姓名、报告和截图。
- 校园身份、供应商密钥、浏览器会话、SSH 私钥、自己的模型服务令牌。
- 用户目录、私人服务器地址、内部运维记录和日志。
- 自己下载的模型权重、运行缓存、Python 虚拟环境。

`scripts/check_publication.py` 检查 Git 跟踪文件或发布目录，发现运行目录、媒体、凭据特征、私人路径和内网地址时阻止通过。扫描器是辅助检查，不能替代人工核对。不要先提交敏感文件再删除，因为旧提交仍保留原文。

这个仓库的首次发布从允许清单创建，不导入私人工作目录的历史。仓库示例与截图仅含合成数据；演示不能作为真实课堂检测能力的证明。
